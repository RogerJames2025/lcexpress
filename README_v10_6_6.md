# LCexpress v10.6.6 — Interfaz completa unificada

Integra las mejoras de clientes, pedidos, productos y reportes sobre la rama con correcciones de PowerSync/correlativos.

## Incluye
- Cliente: Dirección, Teléfono 2, Correo y Observación.
- GPS con acceso directo a Google Maps.
- Producto: Categoría, Caja y Maleta como campos editables con autocompletado.
- Pedido: vendedor por cada ítem, por defecto el usuario conectado, editable por fila.
- Precio: teclado decimal en móvil, foco automático al agregar producto y formato 1,000.00.
- PDF del pedido: incluye dirección, no muestra vendedor por ítem.
- Reporte PDF de ventas por vendedor/ítem.
- Conserva v10.6.5: correlativo offline seguro y diagnóstico/reconexión PowerSync.
