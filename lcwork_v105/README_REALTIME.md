# LCexpress v10.4 - Sincronización visual en tiempo real

- La interfaz escucha cambios de PowerSync en productos, clientes, rutas, pedidos, detalle, inventario y configuración.
- Cuando otro dispositivo cambia datos, LCexpress recarga las colecciones y actualiza las vistas automáticamente.
- Se espera la primera sincronización antes de sembrar inventario inicial, evitando sobrescrituras desde un dispositivo nuevo.
- Refresco de respaldo cada 5 segundos mientras hay Internet.
