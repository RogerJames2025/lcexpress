# LCexpress v10.7.0

Cambios:
- Historial de pedidos: Ver, Editar, Compartir y Descargar PDF.
- Vista de pedido con Imprimir, Compartir y Descargar.
- Al finalizar un pedido se abre automáticamente el selector nativo para compartir el PDF cuando el dispositivo lo permite.
- Historial de rutas: detalle incluye código de producto.
- Detalle de ruta: Imprimir, Compartir y Descargar PDF.
- Todos los PDF generados usan formato Carta por defecto (vertical u horizontal según reporte).
- Impresión en Windows usa el diálogo de impresión del navegador/SO; normalmente la impresora predeterminada aparece preseleccionada.
