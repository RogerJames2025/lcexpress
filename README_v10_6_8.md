# LCexpress v10.6.8 — Selección estricta de catálogos

En Nuevo/Editar producto, Categoría y Caja deben coincidir exactamente con un registro activo del catálogo. Maleta, si se informa, también debe existir y estar activa; puede quedar vacía cuando el producto no se transporta en maleta.

Los campos siguen permitiendo escribir para filtrar las sugerencias del navegador, pero un texto arbitrario no se guarda. Para agregar nuevos valores, use el mantenimiento de Catálogos.
